Entry for the make.fun bounty **"The Meeting That Should Have Been an Email"**
(`u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9`).

## The joke

> We spent an hour in a meeting about the email nobody read, writing an email nobody will read.

One line, 93 characters, one sentence — a meeting about an unread email that
produces another email nobody will read. The loop is the punchline.

## Run

```bash
python3 main.py
```

Writes the single joke line to `/output/entry.txt`. The program validates the
entry first (1–200 characters, single line, exactly one sentence ending in
`.`, contains "meeting" and "email", no double spaces) and is fully
deterministic — no network, no input files.
